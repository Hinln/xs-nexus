# Protocol 目录规则

本目录属于最高风险用户态模块。

- 不自创密码学原语；
- 不复制 WireGuard、Tailscale、Nebula 或其他协议包格式；
- 所有字段必须在 `docs/XSP1_PROTOCOL.md` 中定义；
- 所有状态机必须有图或表；
- 所有输入必须做长度、范围、版本和状态验证；
- 包头认证字段必须明确；
- nonce 和序列号不得复用；
- 每方向独立密钥；
- 重放窗口必须有边界测试；
- Key Epoch 切换必须有乱序测试；
- 过期和吊销凭证必须拒绝；
- 网络 ID、节点 ID 和协议版本必须绑定进握手；
- 不返回可被利用的详细密码错误；
- 不把密钥写日志；
- 每次协议变更必须：
  1. 更新文档；
  2. 更新测试向量；
  3. 更新 Fuzz corpus；
  4. 更新威胁模型；
  5. 记录兼容性；
  6. 运行完整协议回归。
- 内部测试不得写成“已经过安全审计”。
