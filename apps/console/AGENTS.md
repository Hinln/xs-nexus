# Console 目录规则

本目录规则继承根目录 `AGENTS.md`，并追加：

- 所有状态必须来自真实 API 或明确测试夹具；
- 不得硬编码“在线”“直连”“健康”等成功状态；
- 每个数据页面必须有 loading、empty、error、forbidden；
- 高风险操作必须确认并显示影响；
- 统一中文术语；
- 不把内部错误堆栈直接展示给普通用户；
- 不在前端存储长期节点密钥或管理秘密；
- 权限控制不能只靠隐藏按钮，后端必须验证；
- 所有页面添加 Playwright 测试；
- 视觉变更必须运行 `VISUAL_QA.md`；
- 不因截图差异直接批量更新基线；
- 浏览器 Console 和网络错误必须解释；
- 组件必须支持键盘、焦点和可访问名称；
- 表格必须处理长 IP、长节点名和大量数据；
- 禁止无意义动画和虚假网络流动效果。
