# 安全假设与未解决风险

状态：M0.2  
日期：2026-07-29

## 1. 端点与操作系统

- Linux 内核、Windows 内核和系统随机数发生器按其安全模型工作；
- root、SYSTEM 或设备管理员可读取本机节点身份并完全控制该节点；
- 普通低权限进程不能读取节点私钥或访问 Agent 管理 IPC；
- TUN、Netlink、NetAdapterCx 和 WDF 官方接口不会被项目绕过；
- Windows 驱动只在测试 VM 通过后进入真实设备门禁。

## 2. Controller

- Controller 是网络成员、地址、策略和在线凭证的高权限签发者；
- Controller 在线密钥可能被攻陷，因此必须可轮换、可吊销并受审计；
- Controller 不保存节点私钥，也不参与普通业务数据加解密；
- 更新离线根私钥不存放在 Controller 服务器；
- Controller 短时离线期间，最近有效配置继续，但新授权和吊销传播暂停。

## 3. Relay

- Relay 被视为不可信但可用性相关的转发方；
- Relay 可以观察源地址、时间、包长、有限会话标识和目的转发槽；
- Relay 不应获得节点长期密钥、XSP/1 会话密钥、虚拟 IP 业务载荷或明文；
- Relay 可以丢包、延迟、重复和重排，Agent 必须安全处理；
- Relay 大规模 DDoS 仍需要云侧防护，协议限速不能消除全部容量攻击。

## 4. 密码学

- Ed25519、X25519、HKDF-SHA-256、ChaCha20-Poly1305 和 SHA-256 通过成熟库调用；
- 操作系统 CSPRNG 能生成不可预测的长期和临时密钥、nonce 和 Session ID；
- X25519 临时私钥在握手结束后清零，长期身份密钥不用于加密；
- AEAD 同一密钥下的 96 位 nonce 永不复用；
- 协议组合尚未经过独立安全审计，不能宣称生产级安全；
- v1 不支持 0-RTT 和会话恢复，避免早期数据重放与复杂状态。

## 5. 时间

- 节点通常能获得误差不超过 300 秒的墙上时间；
- 时间不是握手反重放的唯一依据，握手 nonce、重放缓存和会话状态独立工作；
- 大幅时间异常时，已建立会话可在凭证和策略允许范围内继续，新注册和新握手进入明确受限状态；
- 配置版本和序列号使用单调逻辑，不依赖墙上时间递增。

## 6. 网络

- Internet、局域网、NAT、Relay 和对端都不可信；
- UDP 可能丢失、重复、乱序、分片或被完全封锁；
- Agent 不能假设源 UDP 地址代表节点身份；
- 默认 TUN MTU 为 1280，v1 不实现自定义业务分片；
- 项目不会自动覆盖默认路由、管理网段或冲突前缀；
- 网络实验优先在 namespace 内执行。

## 7. 配置和策略

- Controller 配置签名公钥通过安装或受控轮换建立信任；
- Agent 持久化最近有效配置版本和哈希；
- 策略默认拒绝，发送端与接收端均执行；
- 子网发布需要管理员审批，Agent 本地发现只能提出建议；
- Controller 被攻陷可能签发恶意但格式有效的配置，因此需要审计、最小管理员权限和紧急根轮换。

## 8. 更新供应链

- 发布清单由离线根或其受限委托密钥签名；
- Agent 同时校验签名、哈希、平台、架构和版本单调；
- 构建系统、依赖锁文件和 SBOM 可追溯；
- 未签名安装脚本、镜像 tag 漂移和在线服务器持有根私钥均不可接受；
- 正式更新私钥和驱动签名属于人工门禁。

## 9. 数据库与秘密

- 正式环境数据库和 Redis 不暴露公网；
- 当前临时环境的公网暴露记录为 `KI-006`，在解除前阻塞最终安全验收；
- 真实秘密只存放在仓库外受限文件或 Secret；
- PostgreSQL 是事实源，Redis 数据可重建；
- 备份包含敏感元数据；数据库归档必须直接流式 age 加密、自动复制到独立挂载文件系统，并由离线 identity 定期完成深度验证和恢复演练；
- 数据库主机只持有 age public recipient。正式 identity、其备份和解密授权不进入数据库主机、仓库或自动化证据。

## 10. 明确未解决

- XSP/1 第三方协议和密码学审计；
- Windows 测试签名驱动实机与 standard/UMDF/Application Verifier 已完成；完整 Agent、SCM/Named Pipe/存储、route/DAD/sleep、正式签名和 Windows 10 兼容性仍未解决；
- 真实 NAS 与本地 Windows 验收；
- DNS、生产防火墙和公网 Relay 容量防护；
- 正式备份 identity 仪式、真实异地主机/对象存储和生产恢复演练；
- 管理员恶意行为的强隔离和审计外送。

## 11. 失败关闭策略

遇到未知版本、签名错误、配置回退、凭证过期、源身份不匹配、重放、AEAD 错误、路由冲突或恢复状态不确定时，默认拒绝新流量并保留最近明确有效的配置。不得通过关闭校验、接受旧版本或修改默认路由恢复“可用性”。
