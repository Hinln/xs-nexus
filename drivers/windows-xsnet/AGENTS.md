# Windows xsnet 驱动目录规则

本目录为极高风险模块。

- 不使用 Wintun、TAP-Windows 或第三方虚拟网卡驱动；
- 可以参考 WDK 官方接口文档，但不得复制来源不明代码；
- 驱动只负责虚拟 NIC 与受控用户态 IPC；
- 加密、握手、ACL、NAT、Relay 和复杂路由不得进入内核；
- 所有 IOCTL、共享缓冲区和数据包长度均视为不可信；
- 必须验证调用方权限；
- 必须处理取消、关闭、Agent 崩溃、设备移除、睡眠和升级；
- 所有锁、引用计数和生命周期必须可解释；
- 不允许内核日志包含密钥或业务数据；
- 不允许在用户日常电脑做首轮测试；
- 每轮驱动安装前创建 VM 快照；
- 编译成功不等于实机通过；
- 测试签名不等于正式签名；
- Driver Verifier 没有实际报告时不得标记通过；
- 蓝屏、无法启动、卸载残留均为 P0/P1；
- 安装器必须可回滚；
- Agent 不存在时普通系统网络必须正常；
- 驱动版本必须与 Agent 协商；
- 正式发布前必须记录：
  - WDK 版本；
  - Windows 版本；
  - 签名状态；
  - Driver Verifier；
  - 安装/卸载次数；
  - 崩溃结果；
  - 已知限制。
