# XS-2026-0002 对称 NAT 模型错误允许广告端口入站

- 标题：对称 NAT 负向模型错误接受 DNAT 到广告端口
- 严重级别：P2
- 发现时间：2026-07-30 09:23 UTC
- 环境：Ubuntu 26.04 LTS，Linux namespace，nftables NAT 矩阵
- 版本和提交：基于 `22751e4` 的 M2.2 工作树
- 前置条件：一端使用端点依赖源端口映射，双方候选仍广告固定端口
- 复现步骤：运行 `scripts/test-agent-nat-matrix.sh` 的 `symmetric-nat` 场景
- 期望：没有可匹配的 Direct 候选，认证会话在观察窗口内不建立
- 实际：测试过滤规则错误允许公网固定端口 DNAT 入站，导致 Direct 会话建立
- 日志：定向回归终端输出；失败后临时 namespace、veth 和 nftables 均由 trap 清理
- 根因：测试模型把 `symmetric` 与 `full` 共用入站允许规则，没有体现端点依赖映射的不可预测端口
- 修复：对称 NAT 场景只允许出站建立不同源端口映射，不接受广告固定端口入站
- 回归测试：完整 M2.2 NAT 矩阵和 `scripts/validate-m22.sh` 均通过
- 相关提交：M2.2 完成检查点
- 状态：已关闭
